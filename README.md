# Lanceur VSF Sponsoring (GitHub Pages)

Page d'installation + manifeste PWA. L'application reste sur Apps Script (`/exec`) : le lanceur n'affiche rien d'elle dans une iframe (la connexion Google reste intacte).

## Mise en ligne
1. Créer le dépôt public `vsf-sponsoring` sur GitHub (compte `phsouchal63`).
2. Renseigner l'URL `/exec` dans `config.js`.
3. Téléverser tout le contenu de ce dossier à la racine du dépôt (Add file > Upload files).
4. Settings > Pages > Source : branche `main`, dossier `/ (root)`.
5. Adresse : `https://phsouchal63.github.io/vsf-sponsoring/`

## Limites
- Chrome / iOS peuvent afficher une fine barre d'adresse sur l'application ouverte (domaine Google).
- Les icônes viennent de `Icones VSF/06-sponsoring` (copies, pas de lien).
